# My Tasks

A responsive task management application built with HTML, CSS, and modular JavaScript.

## Live Demo

https://viktoriahryvniak.github.io/my-tasks/

## Features

- Create, delete tasks
- Save tasks in LocalStorage
- Responsive layout
- Dark mode
- Modular JavaScript structure
- Reusable HTML partials

## Technologies

- HTML5
- CSS3
- JavaScript
- JavaScript Modules
- LocalStorage
- HTMX
- Git and GitHub
- GitHub Pages

## Project Structure

- `css/` — application styles and responsive layout
- `js/` — JavaScript modules and application logic
- `index.html` — main application page
- `index.main.partial.html` — main task interface
- `index.sidebar.partial.html` — sidebar component

## What I Practiced

- Working with DOM events
- Organizing JavaScript into modules
- Saving and retrieving data with LocalStorage
- Implementing responsive layouts
- Creating and managing application state
- Using Git and GitHub for version control
